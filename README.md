## 🔄 Автоматическое обновление

Расширение поддерживает **встроенную систему обновлений** — вы всегда будете в курсе, когда выйдет новая версия, и сможете обновиться в один клик.

### Как это работает

- При каждом запуске расширения оно **проверяет наличие новой версии** на GitHub.
- Проверка проходит **раз в 6 часов** — не чаще. Результаты кэшируются, чтобы не дёргать сервер зря.
- Проверка **тихая**: она не мешает просмотру и не отвлекает, пока нет реального обновления.

### Как узнать, что доступно обновление

Если на GitHub появилась новая версия, вы увидите это сразу в двух местах:

- **🟡 Жёлтая точка** в правом верхнем углу кнопки настроек **⚙️**.
- **🟡 Жёлтая иконка ↻** в шапке панели настроек (вместо обычной серой).

### Окно обновления

Нажмите на иконку **↻** в панели настроек, чтобы открыть окно обновления. Там вы увидите:

- **Текущую версию** — та, что у вас установлена.
- **Новую версию** — та, что доступна на GitHub.
- **Дату обновления** — когда новая версия была опубликована.
- **Описание изменений** — что именно появилось или изменилось в новой версии.
- **Кнопку «Обновить сейчас»** — открывает страницу установки в Tampermonkey.

### Ручная проверка

Если хотите проверить наличие обновлений вручную, откройте панель настроек (⚙️) → иконку **↻** → нажмите кнопку **«Проверить обновление»**. Расширение свяжется с GitHub и покажет результат.

Возможные состояния:

- **✓ Всё актуально** — у вас последняя версия.
- **⬆ Доступна новая версия** — показывается окно с описанием изменений и кнопкой обновления.
- **⚠ Не удалось проверить** — проблема с сетью или GitHub. Можно нажать **«Повторить»**.

### Что происходит после нажатия «Обновить сейчас»

Открывается страница установки скрипта в Tampermonkey. Менеджер скриптов сам предложит установить новую версию — просто подтвердите. Все ваши настройки, закладки и положение кнопок сохранятся.

## 🌐 Поддержка браузеров

> На **ПК** расширение работает в Chrome, Edge, Opera, Яндекс.Браузере и Firefox.
> Ниже — браузеры для **смартфонов и планшетов**.

| Платформа | Браузер | Поддержка |
|-----------|---------|-----------|
| **Android** | ⭐ **Firefox** | ✅ Полная (рекомендуется) |
| Android | Edge | ✅ Полная |
| Android | Lemur Browser | ✅ Полная |
| Android | Quetta Browser | ✅ Полная |
| Android | Kiwi Browser | ⚠️ Ограничена (устарел) |
| **iOS / iPadOS** | Safari + Userscripts | ✅ Полная |
| iOS / iPadOS | Teak Browser | ✅ Полная |
| iOS / iPadOS | Gear Browser | ✅ Полная |

### ⭐ Почему Firefox?

- **Firefox для Android** — единственный браузер, где Tampermonkey ставится напрямую из официального магазина дополнений.
- Не требует режима разработчика, ручной установки `.crx`-файлов или возни с правами.
- Стабильная работа userscript «из коробки».

> 💡 **Для Android**: скачайте Firefox из Google Play → установите Tampermonkey → добавьте скрипт.
> 💡 **Для iOS**: установите приложение **Userscripts** (бесплатно в App Store) и включите его как расширение в Safari.

## 🔄 Синхронизация закладок

Расширение позволяет **переносить закладки между устройствами** без сторонних сервисов и регистрации. Три способа:

### 🔗 Через ссылку
1. Откройте панель закладок (кнопка **📑**).
2. Нажмите **🔗** — панель переключится в режим «Поделиться».
3. Нажмите **📋** — ссылка скопируется в буфер обмена.
4. Отправьте ссылку себе любым способом (Telegram, email, заметки).
5. Откройте ссылку на втором устройстве — закладки добавятся автоматически.

### 📱 Через QR-код
1. В режиме «Поделиться» (кнопка **🔗**) нажмите **📱 Показать QR-код**.
2. Отсканируйте QR-код телефоном.
3. Откройте появившуюся ссылку — закладки импортируются.

### 💾 Через файл
1. В режиме «Поделиться» (кнопка **🔗**) нажмите **💾 Экспорт** — сохранится JSON-файл.
2. Перенесите файл на другое устройство (Telegram, облако, флешка).
3. Нажмите **📥 Импорт** и выберите файл.

> ⚠️ **Важно**: чтобы импорт сработал, на втором устройстве тоже должно быть установлено расширение Кинопоиск [Free].
